TONG QUAN PROJECT ERIS
======================

Project nay la mot he lai:

- Godot + C#: phan "than" cua nhan vat, phu trach hien thi, UI/chat, animation, am thanh va tuong tac.
- Python: phan "nao" AI, phu trach telemetry, nhan thuc, suy luan, memory, parser va dieu phoi hanh vi.
- UDP: cau noi giao tiep giua Godot va Python.
- llama-server / model.gguf: bo phan sinh quyet dinh va hoi dap.

Tom tat ngan:
Godot la body, Python la cognition/runtime, UDP la day than kinh, con model la bo may ra quyet dinh.


1. Tang Godot / C#
------------------

`project.godot`
- Cau hinh du an Godot.
- Scene khoi dong la `body/UdpListener.tscn`.
- Bat C# / .NET.

`Eris.csproj`
- Project .NET cho script Godot.
- Target `net8.0`.

`body/UdpListener.tscn`
- Scene goc cua app.
- Dung `CanvasLayer`, `ChatPanel`, `CharacterContextMenu`, `CharacterBody2D`, bubble text.
- Gan script `UdpListener.cs`.

`body/UdpListener.cs`
- File trung tam ben Godot.
- Bind UDP cong `4242`.
- Nhan JSON tu Python.
- Parse `text`, `animation`, `direction`, `motion`.
- Cap nhat bubble chat, typewriter effect, chat panel.
- Gui tin hieu chat ve Python qua cong `4243`.
- Khoi chay `vision.py`.
- Khoi chay `llama-server`.
- Phat sound theo animation.
- Xu ly chuot phai `force_speak`.

`body/MotionController.cs`
- Tach state machine chuyen dong khoi `UdpListener`.
- Phu trach `walk`, `walk_to`, `face`, `climb_loop`, `climb_to_top`, `drop`, gravity, va collision.
- Giu huong sprite va bubble.
- Day la "bo may animation vat ly".

`asset/Resource/Monika.tscn`
- Dinh nghia `AnimatedSprite2D`.
- Mapping ten animation sang danh sach frame PNG.

`asset/Resource/chat.tres`, `asset/Resource/point.tres`
- Resource atlas cho icon UI.

`asset/Monika/*.png`, `asset/Monika/sound/*.wav`
- Tai nguyen hinh anh va am thanh cho cac animation nhu `stand`, `read`, `sleep`, `climb`, `affection`.

`*.import`, `*.uid`
- Metadata cua Godot.
- Khong phai logic nghiep vu.


2. Tang Python Runtime
----------------------

`src/vision.py`
- Entrypoint Python.
- Cau hinh log.
- Khoa single-instance bang `.vision.lock`.
- Tao `AttentionOverseer`.
- Build service.
- Goi `RuntimeCoordinator.run_loop()`.

`src/runtime/coordinator.py`
- Trai tim cua he thong.
- Nhan cac tin hieu `chat_start`, `chat`, `chat_end`, `force_speak`.
- Chup telemetry dinh ky.
- Dung "cognitive frame" qua cac module SE / Attention / Appraisal / SelfModel / SpeechCore / ActionPlanner / Ni / Ti / Fe.
- Chay them `SubconsciousLoop` nen rieng de tao seed noi tam tru tuong cho autonomous.
- Goi LLM de sinh `Decision`.
- Co post-generation guard cho `force_speak` inner thought: chan cac cum withdrawal/no-signal lap lai nhu `lui lai`, `khong can noi gi`, `Ngai cu lam viec`, va ep text phai khop `inner_thought.intent`.
- Commit memory va gui ket qua sang Godot.

`src/domain/decision.py`
- Dataclass chuan hoa output cuoi cung.
- Gom `text`, `animation`, `direction`, `target_x`, `next_animation`, `system_action`, `motion_intent`.
- Day la "hop dong" giua AI runtime va Godot.

`src/transport/udp.py`
- Transport 2 chieu bang UDP.
- Gui quyet dinh sang Godot va poll tin hieu tu Godot.

`src/app_logging.py`
- Log formatter theo nhom nhu `Vision`, `LLM`, `Loop`, `Action`.


3. Tang LLM
-----------

`src/llm/client.py`
- HTTP client noi chuyen voi `llama-server` hoac OpenAI-compatible API.
- Co 2 lop:
  `LlamaServerClient`
  `OpenAICompatibleClient`

`src/llm/process_manager.py`
- Tai su dung server dang chay hoac tu spawn `llama-server.exe`.
- Nap `model.gguf`, `mmproj-F16.gguf`.
- Cho server san sang.

`src/llm/service.py`
- Lop "boc" model.
- Ep model tra ve JSON hop le.
- Sua JSON loi.
- Fallback neu model tra prose.
- Sinh directive, chat reply, va screen facts.
- Prompt inner-thought co contract rieng cho `curious_question`, `inner_whim`, `random_chatter` de tranh intent label mot kieu nhung raw text mot kieu.

`src/llm/contracts.py`
- Dinh nghia prompt, rule, GBNF grammar, animation whitelist, system action whitelist.
- Noi quy dinh "model phai tra JSON nhu the nao".

6. Tang Nhan Thuc
-----------------

`src/cortex/attention.py`
- Cham diem percept nao dang chu y nhat.
- Tao `AttentionCandidate` va `CognitiveBroadcast`.

`src/cortex/ni.py`
- Danh gia `attention drift` tu focus, window, browser, memory va current text.
- Tra `drift_score`, `drift_level`, `confidence`.
- Co `NiStateMachine` de lam muot trang thai theo thoi gian.

`src/cortex/ti.py`
- Lop governor.
- Dat mode nhu:
  `steady_observe`
  `chat_code`
  `chat_emotional`
  `resource_guard`
- Kiem tra capability violation.
- Chinh cau chu de bot giong bao cao / meta / quyen luc gia.

`src/cortex/fe.py`
- Dinh giong tra loi, warmth, sarcasm, continuity, session arc.
- Tuc la quyet dinh "noi theo kieu nao".

`src/cortex/appraisal.py`
- Dung trang thai appraisal tien-ngon-ngu nhu `threat`, `certainty`, `intimacy`, `protectiveness`, `tenderness`.
- Day la lop "sac thai noi tam van hanh".

`src/cortex/internal_state.py`
- Giu trang thai lien tuc dai hon mot frame, khong phai bang chung ve cam xuc that.
- Theo doi cac truc co ban nhu `valence`, `arousal`, `curiosity`, `boredom`, `social_energy`, `attachment`, `fatigue`, `silence_pressure`.
- Da co them cac truc ap luc hanh vi:
  `social_pressure`
  `curiosity_pressure`
  `protective_pressure`
  `tender_pressure`
  `playful_pressure`
  `watchful_pressure`
  `restraint_pressure`
  `subconscious_pressure`
  `memory_replay_pressure`
  `association_pressure`
- Commit moi turn de cap nhat streak im lang/noi, recent speech acts, recent subconscious seeds, recent self-state labels.
- Render prompt context cho LLM theo rule: chi dung de giu rhythm/continuity, khong duoc xem la bang chung man hinh hay cam xuc an cua user.

`src/cortex/self_model.py`
- Tao `SelfState` runtime cho ERIS.
- Danh gia cac nhan nhu:
  `settled`
  `watchful`
  `engaged`
  `overloaded`
- Tinh `overload`, `engagement`, `initiative_bias`, `brevity_bias`, `embodiment_bias`.
- Neu overloaded thi thien ve ngan gon, it chu dong, han che animation bieu cam.
- Neu engaged thi cho phep chu dong va bieu cam hon, nhung van bi rang buoc boi grounding.
- Context cua self-state duoc ghep vao prompt cung persistent internal state.

`src/cortex/subconscious.py`
- Tao cac "seed" noi tam tru tuong, khong tu tao cau noi truc tiep.
- Co cac mode:
  `memory_replay`
  `associative_drift`
  `attention_drift`
  `quiet_self_muse`
- Dung internal pressure, idle time, focus pattern, long-term memory va recent seeds de chon seed.
- Co repeat guard, novelty check, restraint suppression va risk flags nhu `no_screen_claim`, `anti_mindreading`, `needs_generation`.
- `SubconsciousLoop` chay nen theo interval `ERIS_SUBCONSCIOUS_INTERVAL_SEC`, co the tat bang `ERIS_SUBCONSCIOUS_LOOP=0`.
- Autonomous loop pop seed tu queue, moi seed chi duoc tieu thu mot lan.

`src/cortex/inner_thought.py`
- Sinh dong co xa hoi nhe cho `force_speak` hoac autonomous khi thieu signal man hinh.
- Co the bien `SubconsciousSeed` thanh `InnerThought` khi pressure/novelty du cao.
- Van co repeat guard va safety flags de tranh lap lai hoac bia noi dung man hinh.

`src/cortex/speech_core.py`
- Quyet dinh co nen noi khong.
- Neu noi thi noi tu nguon nao: vision, telemetry, freeform, hay random.
- Chon `utterance type`.
- Da them `MotivationalPressureReport`: cac urge canh tranh voi nhau truoc khi noi.
- Cac urge hien co gom screen vision, screen telemetry, force_speak presence, protective guard, tender check-in, subconscious seed, social presence, curiosity, playful aside, watchful boundary va silence restraint.
- Autonomous phai vuot threshold moi duoc noi; threshold tang khi self-state overloaded va giam nhe khi engaged.
- Tin hieu man hinh cu the van uu tien hon subconscious/freeform.

`src/cortex/action_planner.py`
- Chon speech act truoc khi goi LLM nhu `observe`, `protect`, `mirror`, `reassure`, `system_action`, `withdraw`.
- Nhan `SelfState` de chinh animation hint va notes.
- Overloaded self-state lam giam hanh vi bieu cam tu phat; engaged/expressive co the chon animation am hon nhu `affection` hoac `hop` khi phu hop.

`src/cortex/tune_ni_focus.py`
- Script offline de tune bias / scale cho Ni dua tren log drift thuc te.

10. Luong Chay End-to-End
-------------------------

1. Khi mo app, Godot vao `UdpListener.tscn`.
2. `UdpListener.cs` bind cong `4242`, lay node nhan vat, bubble, chat UI, roi co khoi dong `llama-server` va `vision.py`.
3. `vision.py` tao `RuntimeCoordinator`, `UdpTransport(send=4242, recv=4243)`, memory store, parser, telemetry, Ni / Ti / Fe / Attention / Appraisal / SpeechCore / ActionPlanner.
   - Coordinator cung tao `SelfModelEngine` va `SubconsciousLoop`.
4. Trong vong lap autonomous:
   - `SubconsciousLoop` chay nen, thinh thoang tao seed tu internal state / memory / telemetry.
   - Chup telemetry.
   - Co the chup man hinh de rut `vision_facts`.
   - Goi `SeLens` de dung snapshot.
   - Goi `Ni` de tinh drift.
   - Goi `Ti` de chon mode hanh vi.
   - Goi `Fe` de chon style.
   - Dung `CognitiveFrame`.
   - Chon percept noi bat, appraisal, self-state, speech core, action plan.
   - Autonomous pop mot subconscious seed neu co; seed nay co the di vao `InnerThought` roi `SpeechCore`.
   - `SpeechCore` cho cac urge canh tranh bang motivational pressure, roi moi quyet dinh noi/im lang.
   - Sau do moi goi `LlmService.generate_directive()`.
5. Ket qua model di qua `DecisionParser`, roi qua `TiGovernor.enforce_decision()`.
6. Neu co `system_action` thi `ActionExecutor` chay that.
7. Sau cung runtime commit memory/internal state va `transport.send_json(decision.to_payload())`.
8. Godot nhan JSON, `ParseAndApply()` lay text de hien bubble, lay `motion_intent` / `animation` / `direction` / `target_x` de dua vao `MotionController`, roi phat sound va animation tuong ung.
9. Trong chat mode:
   - Godot gui `{"type":"chat","message":"..."}` sang Python qua `4243`.
   - Coordinator build context chat.
   - Co the dinh kem screenshot neu can.
   - Goi `generate_chat_reply()`.
   - Parse lai va gui `Decision` ve Godot.
10. Trong `force_speak`:
   - Coordinator di qua nhanh rieng.
   - Neu co signal man hinh thi noi grounded.
   - Neu khong co thi `InnerThoughtEngine` + `SpeechCore` tao mot line "hien dien xa hoi" khong bia man hinh.
   - Force speak van duoc noi ke ca self-state overloaded, nhung noi ngan va giam freeform neu can.
   - Sau LLM/Ti, runtime ap dung intent-alignment guard:
     `curious_question` phai la cau hoi; `inner_whim` va `random_chatter` khong duoc bien thanh refusal/no-signal/withdrawal.
   - Neu model recycle personality phrase nhu `lui lai`, `khong can noi gi`, `Ngai cu lam viec`, coordinator thay bang fallback nho duoc xoay vong va gan debug trace nhu `intent_alignment_guard` hoac `phrase_family_guard`.


11. Diem Quan Trong Khi Doc Project
-----------------------------------

- `UdpListener.cs` van gom qua nhieu trach nhiem cung luc: UI, process management, audio, networking, parse payload, animation fallback.
- `MotionController.cs` la buoc tach tot, nhung `UdpListener` van la "god object" ben C#.
- `runtime/coordinator.py` cung la "god object" ben Python: gan nhu moi lop deu tu ve day.
- Neu muon phan tich sau hon, day la file nen uu tien doc nhieu vong.
- Project co dau hieu vua phat trien tinh nang vua nghien cuu prompt / cognition / training, nen co cam giac "runtime that + lab du lieu" song chung mot repo.
- Co hardcoded key trong `body/UdpListener.cs` va `src/actions/executor.py`.
- Day la diem rui ro bao mat dang chu y.
