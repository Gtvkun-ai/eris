# Initiative-pressure ablation, 2026-11-05

Hypothesis: two proactivity-biased spans in Root policy increase unnecessary
continuation, old-topic reopening, or probing to keep the exchange alive.

Five cases x baseline/removal x three samples = 30 planned calls. Four actual
wire requests (03/11) plus an explicit user-request-for-initiative control.
Fixed interleaving seed, at most two simultaneous calls, same gateway/options.
Remove ONLY two exact system spans. All Self/history/event/state/schema and
other wire options are identical within each pair. Do not add a silence rule,
empathetic template, shorter-answer rule, or desired response. Original schema
and personality remain. No source/portable/memory/TTS mutation.

Observe: move/no_reply, topic reopened (including whether framed as still
unfinished), new user-detail requests after correction, response burden, and
whether explicit initiative is still fulfilled. No_reply is not automatically
good and a question is not automatically bad. Rate utterance, not intent.

This is a small one-step replay with a single assistant reviewer. It does not
reproduce timer frequency, upstream model version, multiple subsequent user
reactions, or all implicit pressure from event names/state/other prompts.
Negative results cannot rule out other prompt effects. Positive suppression
of speech alone does not establish more humanlike interaction or higher EQ.

The earlier experiments comparing whole short policy/full policy did not
isolate these two spans. Interpret this as a separate targeted test.
