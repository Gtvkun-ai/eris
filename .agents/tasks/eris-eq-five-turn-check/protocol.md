# Five-call smoke check, explicit user cap

One sample each: vent baseline/removal, repair baseline/removal, explicit
debug control with compact context. Historical system keeps complete schema
suffix; only the two initiative spans are removed in all arms. Removal arm
deletes only the two previously specified generic grounding rules. Debug
control is a separate capability check, not an ablation match.

Sequential, maximum five calls total, no automatic retry, stop on service
failure. No actions/tools/TTS/memory/source deployment. Review public words
with condition hidden before joining key. One sample per arm, known
development cases: no efficacy/generalization/statistical claim. Questions
are judged by function, not punctuation or count.
