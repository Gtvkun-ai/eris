ERIS V91 — ADAPTIVE COMPANION / DESKTOP INDEPENDENCE
====================================================

Mục tiêu chính
- Eris Desktop là companion độc lập, không phải observer của Eris Code/GitPilot.
- Eris Code chạy 100% theo VS Code + GitPilot; không cần Eris Desktop.
- Eris hiểu user đang học/làm gì chủ yếu từ conversation, Life Horizon và evidence user chủ động đưa cho Eris.
- Skill model chỉ dùng để điều chỉnh cách giải thích/challenge; không biến thành điểm số phán xét user.

THAY ĐỔI LỚN

1. Adaptive Companion Brain mới
   File: runtime/adaptive_companion.py
   - Lưu compact learning topics khi user nói rõ "đang học / muốn học / tìm hiểu...".
   - Lưu compact activities khi user nói rõ "đang làm / project / đồ án...".
   - Kết hợp active H1-H3 từ LifeHorizon thành current activity context.
   - Đọc EngineeringMentor skill evidence chỉ khi đủ confidence/evidence.
   - Chọn stance: companion / peer / teach_guided / challenge_light.
   - "làm luôn" đơn lẻ KHÔNG bị coi là yếu hay bị ép học.
   - Chỉ challenge delegation khi task trùng đúng learning topic đang active VÀ reasoning-ownership risk đủ cao.
   - Mỉa/trêu chỉ phát teasing_opportunity; relationship/affective voice vẫn là authority cuối.
   - Không lưu raw transcript/source/terminal telemetry.

2. Public chat integration
   File: runtime/ai_orchestrated/orchestrator.py
   - Adaptive Companion quan sát foreground user turn trực tiếp từ Eris chat.
   - ADAPTIVE_COMPANION_V91 được đặt sớm trong discourse budget để không bị mentor legacy cắt mất.
   - Không cần Eris Code event stream.

3. Engineering Mentor trở thành evidence layer phụ
   File: runtime/engineering_mentor.py
   - Giữ API V80→V89 để compatibility.
   - V91 ghi rõ Adaptive Companion là higher-level delivery authority.
   - Nếu Companion nói peer/companion/no teaching thì Mentor không được ép lecture.
   - Mentor hoạt động bình thường khi hoàn toàn không có GitPilot/workspace telemetry.

4. Desktop bỏ observer runtime
   File: runtime/coordinator.py
   - Normal startup không mở ErisCodeObserverLink.
   - Không replay GitPilot flow vào Mentor.
   - Không nhận user_intent/workspace telemetry từ extension.
   - Giữ attribute None để code cũ kiểm availability không crash.

5. Eris Code 0.22.0 tách Desktop thật sự
   Files: vscode-extension/*
   - GitPilotClient constructor chỉ còn context + runtime + terminalObserver.
   - Không readProjectContext từ Desktop.
   - Không publish CodingObservation sang Desktop.
   - Không CompanionWorkspaceObserver.
   - Không external-agent observation command.
   - Bỏ toàn bộ erisCode.erisLink.* settings.
   - Self-test kiểm Desktop independence thay vì Companion Observation.

Lưu ý
- Desktop vẫn có thể giữ các module V79/V90 legacy để đọc journal/rollback, nhưng V91 không start chúng và extension không gọi chúng.
- Nếu muốn Eris xem repo/diff/log, user chủ động gửi/cho Eris đọc qua kênh Eris. Đây là feature, không phải regression: V91 ưu tiên relationship/context thật hơn hidden telemetry.
