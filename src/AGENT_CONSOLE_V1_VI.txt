AGENT CONSOLE V1 — GHI CHÚ TÍCH HỢP
===================================

Mục tiêu
- Panel riêng để quan sát task của Gemini/LangGraph theo thời gian thực.
- Không đọc log, không hiển thị raw chain-of-thought.
- Có task list, typed event stream, inspector, test/files/checkpoint.
- User có thể Pause / Resume / Stop / Rollback / gửi directive.
- Eris có bridge riêng để Comment / Advisory / Redirect / Veto executor.

Protocol
- Brain -> Body: type=agent_event
- Brain -> Body snapshot/ack: type=agent_console_ack
- Body -> Brain: type=agent_control

Các file chính
- body/UdpListener.AgentConsole.cs
- runtime/agent_harness/task_store.py
- runtime/agent_harness/event_bus.py
- runtime/agent_harness/supervisor_bridge.py
- runtime/agent_harness/graph_builder.py
- runtime/incoming_protocol_runtime.py
- runtime/incoming_dispatcher.py

Mở panel
- Chuột phải Eris -> Agent Console.

Eris supervisor API
- coordinator.agent_supervisor.comment(task_id, text)
- coordinator.agent_supervisor.advisory(task_id, instruction, reason=...)
- coordinator.agent_supervisor.redirect(task_id, instruction, reason=..., checkpoint_id=...)
- coordinator.agent_supervisor.veto(task_id, reason, instruction=...)

Lưu ý hiện tại
- Rollback được queue ở node boundary; graph control-plane cần hoàn tất phần restore
  checkpoint + workspace snapshot trước khi coi là rollback vật lý hoàn chỉnh.
- Panel đã generic theo executor; hiện nhãn UX ưu tiên Gemini nhưng backend không khóa provider.
